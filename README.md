# Hambank Mobile Web App Prototype

پروتوتایپ موبایلی همبانک برای اجرای استاتیک روی GitHub Pages.

## اجرا

1. همه فایل‌های این پوشه را داخل یک Repository قرار دهید.
2. در GitHub به `Settings > Pages` بروید.
3. گزینه Deploy from a branch را انتخاب کنید.
4. Branch اصلی و پوشه `/root` را انتخاب کنید.
5. لینک GitHub Pages باز می‌شود.

برای اجرای محلی نیز می‌توانید `index.html` را با یک static server باز کنید. به دلیل استفاده از iframe هم‌دامنه برای پرسشنامه، بهتر است فایل‌ها از طریق HTTP سرو شوند؛ مثلاً:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید.

## نکات مهم

- فایل `risk-questionnaire.html` کپی بایت‌به‌بایت فایل پرسشنامه تاییدشده است و داخل آن تغییری ایجاد نشده است.
- سوالات، تصاویر، UI، منطق امتیازدهی و خروجی پرسشنامه ثابت مانده‌اند.
- داده‌های عددی بازار، ارزش روز، بازده، تاریخچه و توصیه‌ها در این Prototype فرضی هستند.
- نام برخی ابزارهای مالی مانند `کهربا`، `کارا`، `کاریس` و نمادهای `فملی`، `فولاد` و `شستا` واقعی‌اند، اما استفاده از آن‌ها در این فایل توصیه سرمایه‌گذاری واقعی محسوب نمی‌شود.
- Reminder دو روزه در منطق state ذخیره می‌شود؛ برای دمو، Action Center همیشه امکان ثبت اجرای نسخه را در اختیار کاربر می‌گذارد.
- LocalStorage برای نگهداری وضعیت کاربر، ثبت‌نام، OTP دمو، اهداف و بدهی‌ها استفاده می‌شود.

## ساختار فایل‌ها

- `index.html` — ورودی اپ
- `styles.css` — UI موبایل
- `app.js` — Journey، state، چهار تب و تعامل‌ها
- `risk-questionnaire.html` — پرسشنامه تاییدشده بدون تغییر
